## 🚀 Local Development

Repository'yi klonlayabilirsiniz:

```bash
git clone https://github.com/ufukgulec/ufukgulec.github.io.git

cd ufukgulec.github.io
```

Proje statik bir web uygulaması olduğundan özel bir backend veya veritabanı kurulumu gerektirmez.

Herhangi bir local HTTP server ile çalıştırılabilir.

Örneğin Python ile:

```bash
python -m http.server 8080
```

Ardından:

```text
http://localhost:8080
```

adresinden uygulamaya erişilebilir.
